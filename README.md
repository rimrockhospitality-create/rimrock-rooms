# Rimrock Rooms

Fast hotel operations WebUI for housekeeping, inspections, maintenance and preventive maintenance.

## Section 1 — WebUI Shell

Locked scope:
- Responsive desktop/mobile shell
- Everhome Suites Denver Airport (CO534)
- Role-ready navigation
- Initial Property and User data structures
- Operational modules intentionally remain placeholders

## Design principle

**Fast on top. Simple for the user. Reportable underneath.**

No Bedrock dependencies. Build and performance are kept deliberately small.

## Local preview

Serve the repository as static files and open `index.html`.

Room inventory will be reconciled and loaded separately before Section 1 closes.
